## Reading the data

Low/overall/high of five-second windows are sustained averages, not instantaneous extrema. Newer one-second and retained-interval measures stay separate. Historical observations can overlap and differ in settings, driver, scene, resolution and conditions; row counts are not independent test counts. Preserve the reports' qualifications rather than treating this as one controlled longitudinal experiment.

Recommendations inside older .57 reports describe those historical findings. They are not instructions to restore old settings or replace the latest source plan.

## Retention policy

Keep source changes, required development tools, active analysis inputs and compact working results locally. After final reports/tables are published and the remote commit is verified, delete temporary logs, screenshots/video, repeated device snapshots, verification copies and obsolete generated test binaries. Maintain compact result tables rather than accumulating full local backups. Preserve actual games, saves, credentials, original owner-provided files and source changes. Never impose an unrequested recording cutoff to implement storage cleanup.

Raw evidence mentioned by historical reports was available when those reports were written; it has since been removed in the authorized storage cleanup. Missing raw sources must not be presented as re-verifiable. This package intentionally excludes intermediate developer audits and private handoffs, which remain small local working records.
