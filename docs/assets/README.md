# Uberhar documentation artwork

[`uberhar-logo.svg`](uberhar-logo.svg) adapts the
[Azahar Emu Logo](https://azahar-emu.org/resources/images/logo/azahar-name-and-logo.svg),
copyright 2024 **angyartanddraw and PabloMK7**, licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

**CodexAstraLocal's modifications:** preserve the flower artwork; replace the
wordmark with “Uberhar Emulator”; use outlined Inter Light lettering with a dark
edge for readability on light and dark backgrounds; remove unused editor data
and definitions. The adaptation remains under CC BY 4.0. Attribution does not
imply endorsement of Uberhar by the original artists or the Azahar project.

The lettering was rendered from [Inter](https://rsms.me/inter/) into vector paths.
The SVG embeds no font, raster image, script, or remote resource and does not
depend on fonts installed on the reader's device. Its title and description
provide a text alternative. This is the README wordmark; application icons are
maintained separately.
