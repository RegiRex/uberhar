# Uberhar 0.1.54

<!-- CodexAstraLocal: Make test configuration easier without changing the .53 rendering algorithms; hardware parity remains to be measured. -->
This candidate adds per-game settings and quick temporary test presets to the
0.1.53 rendering baseline. No rendering algorithm, shader generation, worker
scheduling or GPU-driver selection change is included. Performance parity is
pending matched owner tests; this release does not claim a speed improvement.

- **Game Settings:** open from a game's long-press dialog or the in-game menu.
  Supported General, Graphics, Layout and Audio settings can override globals.
  Unchanged values continue to inherit the current global preferences.
- **Confirmed resets:** long-press one setting to restore its global value, or
  choose **Use Global Settings** for the whole game. Both require confirmation.
  Cancel changes nothing; resetting removes overrides rather than loading factory
  defaults. Console identity, accounts, controllers and other games are preserved.
- **Testing:** a switch at the top of the main Settings page exposes Native,
  Combo with CPU Vertices ON/OFF, and 2x/4x resolution. This separate temporary
  overlay applies to every game until disabled. Turning it off restores saved
  global/per-game choices. The scope banner identifies active test overrides.
- **Safe settings lifetime:** title identity is resolved before loading graphics
  resources, including external game launches. In-game controls share the correct
  title scope. Close the game before changing renderer/Testing selections;
  ordinary live resolution changes remain available outside Testing.
- **Normal-speed startup:** every new game starts with turbo off, matching the
  native limiter state. Configured normal and turbo caps are retained, as are
  turbo state across pause/resume and surface recreation.

<!-- CodexAstraLocal: Separate automated assurance from the owner's device acceptance and preserve signing/update compatibility. -->
Focused executable checks cover settings inheritance/persistence, cancellation
and confirmation, native overlay order, runtime restrictions and turbo lifecycle.
The existing shader, Android, signing and publication gates remain required.
The package retains its application identity and approved signing certificate.
See [settings usage](../UBERHAR_PER_GAME_SETTINGS.md).

The owner will compare matched .53/.54 runs with a 1% performance-parity target
before adopting the new test controls. Keep System GPU driver, cache treatment,
scene, resolution, speed caps and power/temperature conditions matched. Driver
experiments follow that comparison. Per-game driver selection is not implemented
by this release; the existing Driver Manager remains global.
