# Uberhar 0.1.43 — Independent Calculated rendering

<!-- CodexAstraLocal: Describe the integrated experiment separately from device acceptance. -->
This candidate replaces Calculated's rectangle-only test path with independent
Vulkan compute rendering of original guest vertex inputs and ordered triangles.
It executes guest vertex shaders, persistent primitive assembly, clipping and
fragment processing without Native rendering fallback. Unsupported states stop
emulation with an error rather than silently omitting a draw. The Android mode
description now reflects that behavior.

<!-- CodexAstraLocal: Reuse production formulas and cache ownership rather than introducing a second texture/lighting definition. -->
The path reuses production texture, texture-combiner, lighting, fog, alpha and
procedural-texture formulas. It integrates ordered color/depth/stencil/shadow
writes, native target formats, texture descriptors and feedback snapshots with
the existing texture cache and presentation system. Guest GPU work in this mode
runs on the host GPU through compute; CPU Software remains the separate CPU
rendering experiment introduced in .42.

<!-- CodexAstraLocal: State concrete limits so build success cannot be mistaken for whole-game correctness or a speed claim. -->
Calculated is experimental. Guest geometry shaders, debugger execution and some
unsupported graphics/resource states still fail explicitly. Synchronous status
readback, cold pipeline compilation, target conversions and ordered per-pixel
triangle traversal can limit performance. There is no whole-title or Thor speed
qualification yet. Native/Combo and CPU Software retain the .42 improvements.

<!-- CodexAstraLocal: Fix the observed Software startup failure without claiming the unknown device register tuple is reproduced. -->
CPU Software now uses the same stride-limited LCD width as the existing display
backends. This permits valid format/stride register transitions while retaining
strict bounds checks for nonempty scanout. Errors include the screen, address,
format and mapped-span details. The shared error dialog now describes rendering
errors instead of incorrectly labeling every failure as a shader failure.
The .42 dialog's unresponsive OK button remains unexplained.

<!-- CodexAstraLocal: Record the finite host qualification and leave hardware acceptance explicit. -->
The integrated native build, actual Calculated Vulkan-owner checks, affected
legacy gates, and Software startup/capture checks pass. Calculated checks cover
original inputs, complete color/depth output, primitive continuity and 12
resource cases. Software checks exercise actual startup registers and separate
format/stride changes. These results do not qualify complete games on Thor.
See the [source review](../UBERHAR_REVIEW_0.1.43.md).

The candidate is ready for the existing shader, Android, checksum, signing and
publication gates; delivery is pending. The owner will compare .42 and .43
independently. Leave .42 installed until that sequence.
