# Uberhar 0.1.12 — retain pending clip/viewport updates across GPU retries

<!-- AstraPro: Narrow correctness repair; preserve the observed Sonic gain. -->

## Changes

Keep an unuploaded VS clip/viewport block dirty across repeated synchronization.
Previously a ready-GPU attempt could consume register dirty bits, defer before
uniform upload, then let CPU recovery clear the upload flag on an unchanged
second sync. The fix accumulates pending dirtiness until the existing upload path
clears it. Add one lifetime summary counter, `pending_vs_resyncs`, with no extra
per-draw clock or log calls.

No GPU topology/admission, fragment specialization, fixed-GS correction, shader
arithmetic, cache limits, guest clocks, driver workaround, draw-order or saved
settings changes. Native remains available. The 0.1.11 current/old/older logging
and periodic flush improvements remain intact; older stays filesystem-only.
New logical sections use AstraPro; historical attribution is preserved.
