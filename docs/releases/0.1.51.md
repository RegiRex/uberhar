# Uberhar 0.1.51 — remove wasted work and retire Calculated

<!-- CodexAstraLocal: Explain the owner-authorized cleanup and exact performance changes without presenting a build pass as hardware acceptance. -->
This candidate responds to the .48–.50 regression assessment. It removes expanded
standalone CPU batches completely while retaining useful grouping behind an
existing sufficiently large batch, fixed worker limits and ordered output.
The expanded-batch setting is removed from Android and desktop configuration.

<!-- CodexAstraLocal: Structural reuse and impossible-branch pruning reduce actual repeated host/GPU work while preserving mutable inputs and arithmetic. -->
Native/Combo fragment preparation now caches structural shader analysis separately
from numeric constants. Value changes refresh the current arithmetic certificates
from a clean structural base. Static shaders omit certificate branches for channels
that cannot qualify, preserving branches and exact results for eligible channels.
Shader-bank capacity, graphics ownership and required resource barriers are retained.

<!-- CodexAstraLocal: Retirement removes an unusable experimental method rather than leaving dormant runtime dependencies or changing supported mode identities. -->
Calculated is removed from the application, controls and exclusive build/tests.
Saved Calculated selections migrate to Native; other mode identifiers remain stable.
Its previous implementation remains recoverable in the 0.1.50 source history.
Native, Combo, ComboGeneric and CPU Software continue.

<!-- CodexAstraLocal: Software work has real output consumers; preserve invalid-input rejection and avoid advertising a provenance improvement as a numerical cure. -->
CPU Software adds checked integer edge stepping, per-triangle reuse of eligible
constant texture-combiner results, a copy bypass for wholly unclipped triangles,
and earlier rejection of impossible constant-fill groups. Original output and
fallback behavior remain required. Bounded terminal provenance correlates invalid
inputs with actual source values and reads. Dark Moon's nonfinite-input fault is
not claimed fixed; Software remains experimental.

<!-- CodexAstraLocal TEST-ONLY LOG: Remove qualification details after shader/work placement decisions are resolved; retain production errors and reliable final aggregates. -->
Existing sampled GPU passes identify the shaders and state actually selected,
including mixed and missing identities, draw counts and scene-alignment clocks.
This adds no per-draw GPU queries or pass splitting. Per-family omission counts
make missing optional progress diagnostics visible. Software periodic reports use
nonblocking delivery; forced final summaries remain reliable. Neither draw counts,
scissor area nor shader identities establish a measured time saving by themselves.

<!-- CodexAstraLocal: Keep source qualification, publication and gameplay evidence distinct. -->
Validation covers output equivalence, mutable-state invalidation, scheduling and
resource ownership, legacy mode migration, surviving settings and diagnostic loss
accounting. The usual shader, Android, signing and publication gates still apply.
Matched cold-cache device comparisons determine performance, including five-second
lows and scene coverage. Sustained 99% at 2x, then 4x, remains the target.
