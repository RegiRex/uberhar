## Changes

Admit independent no-guest-GS Shader-topology lists to the ready-only GPU vertex
route in Combo. 0.1.8 excluded all 7,199,403 Dark Moon Combo batches by topology;
Kid Icarus promoted only 2,919 batches. This update addresses the excluded topology,
not a proven GPU throughput ceiling. No full-speed result is claimed.

Use shared actual PICA state checks at PICA and Vulkan entry points. Empty assembly
alone is insufficient: a pending Shader winding request must remain on CPU until
consumed. Require matching register/assembler topology and preserve existing
no-debugger, no-guest-GS, complete-triple, size, upload and cache bounds. Retain the
actual guest topology in keys, existing shader arithmetic, fragment support guards,
all full-CPU recovery behavior and driver workarounds. Native remains CPU-based.

Add bounded exclusive admission reasons and actual accepted topology counts.
Include completed GPU work in the existing 4096-batch/five-second reporting gate
so GPU-heavy execution still produces progress evidence. No per-draw timing added.
Settings identify `independent_lists_v2`; renderer diagnostics advance to 20.
New logical sections use AstraPro; prior attribution is retained.

## Validation

Complete local host suite passed. New: 4,992 admission cases, 200,000 readiness
choices, 10,000 production-assembler differentials (6,392 simulated promotions,
3,088 Shader), actual Vulkan topology mapping, pending winding, partial tails,
unknown topology, pipeline deferral/failure and framebuffer cancellation/retry.
ASan/UBSan passed on the new suite. Six integration C++ syntax checks passed after
generated settings headers were prepared. 256 offscreen compute/native rectangle
pixel comparisons plus their Vulkan/SPIR-V checks passed. Local TEV pixels were
interrupted after reporting 8,448 outputs and are not a completed pass.

The unchanged CI shader/pixel/Vulkan, Android, unit, package/signing and publication
gates remain required. Host assembly tests are not GPU shader numerical parity.
More admitted work can increase compiler contention, uploads or driver costs;
measure actual GPU promotion and matched-scene performance. No 0.1.9 APK readiness
or Thor speedup is asserted here. Full compute, guest GS, strip/fan continuation,
FEA ghosting, latency and universal 400%/200% performance are not solved.
