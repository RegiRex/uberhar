# Uberhar 0.1.41 — retain cached shader data through its last draw

<!-- CodexAstraLocal: Fix the lifetime of reused shader data without attributing
the observed title artifacts to a cause that has not been tested on hardware. -->

Vulkan draws can reuse unchanged uniforms and lookup tables without uploading
them again. Previously, the buffer's allocation watch could refer to an earlier
draw that had already completed. A later upload could then wrap the ring and
overwrite those cached bytes while a newer draw still needed them.

The uniform, procedural-texture LUT and lighting/fog LUT rings now record their
last actual draw-use tick. Before a wrap exposes reused writable storage, it
waits through that tick. Stamping happens after the actual accelerated or
CPU/deferred draw enqueue, including any pass, pipeline or index setup that can
flush commands. Pending and no-target returns do not count as draws. Existing
allocation watches and complete cached-block refresh on invalidation remain.

<!-- CodexAstraLocal: State the bounded cost and unchanged rendering contract;
the correction is a real lifetime fix, not a measured throughput result. -->

There is no new per-draw wait or non-wrapping-map wait. The initial correction
uses a conservative fence for the entire cached ring, which may wait longer
than tracking only the overlapping ranges. Shader arithmetic, route admission,
CPU vertex ownership and draw order are unchanged, including the .40 static
TEV tier and full-specialization precedence. No additional CPU work moves to
the GPU.

Regression gates exercise production ring/upload bodies, both accelerated
enqueue sites, CPU/deferred final-tick ordering, and complete cached-block
refresh. A separate Vulkan gate renders distinct uniform and LUT payloads with
real submissions and fences. Missing stamps, early stamps, missing wrap waits
and missing refreshes must fail their specific output checks. Existing build,
shader, Android, package and signing gates remain required.

This fix has not been tested in a Thor title run. It does not establish the
cause of earlier moon or ghost artifacts, a speed improvement, or reduced
memory use. After the gated build and release, all work pauses with a resumable
handoff. Installation and hardware tests wait for the owner's resume.
