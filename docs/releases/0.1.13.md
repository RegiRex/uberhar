# Uberhar 0.1.13 — Native plan reuse and targeted Combo diagnosis

<!-- AstraPro: Independent Native optimization, a bounded writer correction and diagnostic evidence. -->

## Changes

Cache one exact value-only NativeVertexPlan across unchanged register mappings.
Rebuild on changed input mapping/count, output mask or active output semantics.
Never cache guest memory, defaults, vertex data, constants or shader outputs.
This benefits the CPU vertex path in Native and Combo recovery without changing
per-vertex arithmetic or draw order. Hit/build counts use the existing report gate.

Correct Vulkan fixed-attribute reservation from sixteen to seventeen vec4 slots:
the writer includes one default slot plus up to sixteen distinct fixed registers.
Record maximum bytes and old-bound crossings. This corrects a reproduced capacity
contract defect; it is NOT established as Dark Moon's ghost/crash cause.

Add one bounded detail record per optional GPU pipeline: immutable stage IDs,
stage presence, topology, layout counts, attachment formats and driver-build time.
Add sparse synchronized viewport/scissor/clip/target/route snapshots (at most one
per five seconds, checking the clock only every 4,096 prepared draws). These are
host state and preparation evidence, NOT GPU execution times or captured pixels.
A transient single-frame anomaly may still escape the sparse sample.

Keep Sonic's ready GPU vertex and specialized-fragment paths, fallback completeness,
shader arithmetic, geometry correction, driver guards, clocks and cache caps.
Keep current/old/older log retention. New logical sections and diagnostic call
comments use AstraPro; historical attribution is preserved. No workflow, signing,
dependency or permission changes are included in the emulator source commit.

## Evidence

The seven 0.1.12 sessions confirm Dark Moon corruption persists: normal speed
13.753%, 7,719 pending-uniform revisits, 87 optional pipeline builds accumulating
117.200 s of driver creation. This is not a serialized foreground stall estimate.
Sonic's marked complete post-race-start windows average 95.962%; pre-race fast
windows must not inflate gameplay qualification. No controlled further speedup
relative to 0.1.10 is asserted. FEA's accelerated bands are 343.189% Combo and
323.573% Native. LEGO's long runs are BOTH Combo, not a Native/Combo comparison:
pure fixed windows average 395.131% at 2x and 339.423% at 4x; the 4x minimum is
168.804%, below a stable 200% floor. See ../UBERHAR_LOG_ANALYSIS_0.1.12.md.

## Validation

Full host suite passes. Native mapping cache: 168,438 checks against fresh plans
and inherited output conversion, with live payloads, aliases, NaNs, edits and
resets. Fixed writer: 131,072 cases pass; the unmodified parent's writer fails
one maximum-capacity case. Both new tests pass ASan/UBSan. Six integration C++
syntax checks pass with inherited warnings. The writer harness models allocation;
these are not GPU or Android device tests. No new local shader-pixel result is
claimed. Existing full shader/pixel, Android, package/signing and publication
gates remain required. Commit/build/APK readiness is reported at handoff.
