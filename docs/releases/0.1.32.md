# Uberhar 0.1.32 — exact masked Calculated rectangles

<!-- CodexAstraLocal: Explain the functional change and retain complete fallback whenever its exact proof is unavailable. -->

Calculated and both Combo methods can recognize additional solid rectangle
operations: nonzero partial RGBA writes and alpha-endpoint blends that are exactly
equivalent to replacement. Enabled channels receive the computed color; every
disabled byte is preserved. Unsupported operations still render completely
through the existing graphics route. Native retains its previous admission
behavior. This is an expanded exact subset, not a general compute renderer or
independent execution of every draw.

<!-- CodexAstraLocal: State the new proof boundary and preserve the inherited path without silently relaxing its unrelated guards. -->

Only the old ColorWrite and Blend blockers may be reconsidered. Blend equations
must prove source factor one and destination factor zero for both RGB and alpha.
Literal factors and exact source-alpha endpoints are supported. Endpoint proof
follows the final supported Replace-only TEV chain, including constant and
previous values; it is not inferred from the rounded packet alpha byte. Zero
write masks and source-zero/destination-one operations do not fabricate useful
coverage. Depth, stencil, alpha test, clipping, culling, guest scissor, fog,
textures and arbitrary blending retain their prior restrictions.

New admissions additionally require W exactly one, bounded binary32 dyadic X/Y,
an exactly integral viewport projection and identical original shared endpoints.
The original helper still proves the two nondegenerate triangles form one
rectangle and evaluates the supported color chain. Previously accepted states
retain their existing geometry checks. Preparation computes one small draw-local
state result and does not copy the 3,072-byte guest register file.

<!-- CodexAstraLocal: Describe the actual storage/ownership contract and avoid an implied general framebuffer implementation. -->

One formerly unused word in the existing 32-byte packet holds an RGBA byte mask.
The compute shader reads the destination only for a partial mask; full masks
keep their direct store. Partial operations request incoming ShaderRead and
ShaderWrite visibility. The existing validated level-zero RGBA8 surface identity,
ordered command snapshot, outgoing visibility and framebuffer invalidation remain
in use. Each pixel has one invocation owner. The existing area-only automatic
selector can mix full-store and partial read/modify/write costs; this remains a
performance limitation, not a promise that each selected route is faster.

Compute census schema 2 retains the same raw eleven-bit histogram, fixed 32 KiB
storage and reporting cadence. Two scalar totals distinguish raw blockers from
effective state rejection. A newly accepted operation may have a nonzero raw
mask; format, geometry, readiness and selection still determine actual dispatch.
The report checks both accounting relationships. Ranked groups and state-family
upper bounds describe raw masks, not computed pixels.
