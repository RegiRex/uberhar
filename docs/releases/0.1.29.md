# Uberhar 0.1.29 — bind CPU shader execution once per draw

<!-- CodexAstraLocal: Reduce recurring host call preparation while retaining the generated program, invocation order and live state. -->

Eligible CPU vertex draws now bind the compiled shader function, live uniform
address and entry point once after the existing batch setup. The ordinary FIFO
loop uses that borrowed context for each actual shader invocation. This removes
repeated engine dispatch and entry resolution while retaining the same generated
shader code, ABI, register carry, output transport and primitive assembly.
Empty, interpreter, profiler, Custom, debugger, geometry and unsupported-plan
routes retain their applicable inherited behavior. No draw is skipped.

Sampled and explicit timing paths share an allocation-free call adapter so they
execute the same selected shader path without duplicating their complete loops.
The extra adapter call is inside their measured shader interval; those timings
are not uninstrumented workload shares. Ordinary loops have no per-vertex mode
branch or diagnostic adapter.

<!-- CodexAstraLocal: Record measured host tradeoffs rather than promising a device speedup from x64-specific removed work. -->

Private host whole-runner comparisons preserve exact state/output/FIFO/tails
under Release and LTO, with a wrong-entry negative control failing. x64 removes
an expensive label lookup that ARM64 already handles with a stored offset.
ARM64 still avoids repeated host dispatch/preparation, but its title benefit is
unmeasured. The narrowed native compiler object adds about 4 KiB of associated
`LoadVertices` code (19.9%); its main function adds 259 bytes. This is a concrete
code-size tradeoff, not an Android instruction-cache measurement.

<!-- CodexAstraLocal: Keep actual production regression, full integration, release and device acceptance as distinct gates. -->

The durable regression runs real JIT, interpreter, output transport and assembly,
plus extracted production binding/diagnostic call sites. Profiler-off and
profiler-on variants each pass 1,920 full-draw comparisons, including program and
entry rebinding, live uniform updates, empty draws and partial register carry.
Profiler scope entries/leaves balance. Independent source review found no
correctness blocker. The native integration build and all 67 CTest entries pass
or retain their five inherited firmware skips; the full host probe also passes.
Android, shader, signing and publication gates have not run for this candidate.
No 0.1.29 APK is ready and no Thor speedup is claimed.
