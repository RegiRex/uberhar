This follows 0.1.19 on `uberhar/codexastra-diag-comparison`. It runs the existing

identify candidates by commit. Queueing preserves the previous comparison build.

## Changes

- Combo keeps complete draws on the CPU for three more reproduced input mismatches:
  loaded attributes also marked default, strides too short for the final copied
  attribute, and multiple attributes mapping to a requested shader input register.
  Checks run before speculative GPU reads, pipeline work or uploads. The prior
  zero-stride guard, Custom mode and driver workarounds remain intact.
- Each new fallback reason gets at most four records per rasterizer lifetime and
  a final total on orderly teardown. A killed process can lose teardown totals.
- Two exact, valid-buffer AppletUtility signatures now emit four initial warnings,
  then powers of two and a final per-module summary. The owner's Metroid log had
  17,981 repetitions; replay emits 30 warnings and two summaries. Unknown commands,
  changed sizes and malformed buffers retain the original warnings. Guest responses
  are unchanged. No new worker, timer, bundle or runtime dependency is added.
- Retain [0.1.19 optional-progress logging](0.1.19.md) and reliable failure context.

## Evidence and limits

See the [device analysis](../UBERHAR_LOG_ANALYSIS_0.1.17_0.1.18.md) and
[validation/build status](../UBERHAR_PROGRESS.md). All attached gameplay logs are
0.1.17. The 0.1.18 report and startup log establish no frame-performance comparison.
Android classifies both reported exits as low memory; neither allocation ownership
nor Dark Moon's graphical fault is established. Returning to the main menu does not
by itself prove successful renderer-error recovery.

Host probes reproduce the input differences, prove early fallback, and retain
ordinary CPU/GPU input parity. APT tests exercise production bodies and IPC replies.
These are not full Vulkan game-image tests. The game upload failed and this cloud
host has no Thor Max/Adreno performance model. More CPU fallback can reduce speed;
there is no claimed Dark Moon cure or measured speedup.
