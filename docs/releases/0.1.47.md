# Uberhar 0.1.47 — descriptor reuse and split Calculated vertex processing

<!-- CodexAstraLocal: Describe actual changes separately from hardware acceptance. -->
Native/Combo removes repeated image-descriptor allocation and writes when the
exact texture and utility bindings remain unchanged within one submission tick.
Resource resolution, feedback copies, shader selection, draw order and actual
descriptor binding still execute. Descriptors are finalized immediately before
their consuming command, after preparations that can submit work. Image-view and
sampler retirement invalidate reuse before numeric handles can be recycled.
Storage is bounded to one last value per image descriptor heap and requires no
saved shader cache. Both declared utility bindings remain initialized.

<!-- CodexAstraLocal: Preserve workload placement choices and avoid occupancy claims. -->
CPU Vertices remains separately selectable and defaults OFF. This change adds
no GPU arithmetic, worker pool, artificial CPU occupancy or draw skipping. Sonic
and Dark Moon need different placement choices; on-device speed and pacing for
this candidate remain to be measured.

<!-- CodexAstraLocal: Decode reuse is local to an admitted immutable row group. -->
CPU Software reuses exact requested texel decodes within existing joined row
work, including filtering and packed shadow taps. It admits this reuse only when
all consumed texture mip/face ranges are disjoint from the output and concurrent
guest memory writers are excluded. Live feedback retains direct reads. Full
Copy blends with every channel enabled avoid an unnecessary destination-color
read. Filtering, depth/stencil, quantization and demanded invalid coordinates
retain their existing behavior.

<!-- CodexAstraLocal: First-fault diagnostics are not represented as a crash fix. -->
A bounded local Software producer capsule retains the first demanded nonfinite
semantic value with shader code, uniforms, inputs, output mapping and explicit
replay limits. It neither substitutes Native nor repairs invalid values. Temporary
diagnostics carry `CodexAstraLocal TEST-ONLY LOG` markers and removal conditions.
Fire Emblem's upstream nonfinite-coordinate failure remains unresolved.

<!-- CodexAstraLocal: Concrete driver-compatibility candidate uses the captured .46 failure. -->
Calculated separates guest vertex/FIFO execution from ordered assembly and
clipping. Both pipelines must exist before dispatch; a compute dependency carries
semantic scratch into the second stage, which alone publishes final success and
primitive state. One final status readback remains. Float uniforms are read from
the immutable captured buffer rather than copied into a large private array;
indirect addressing and arithmetic are preserved. Graphics decompiler callers
retain their previous uniform path. No Native fallback or unsupported-draw skip
is introduced.

<!-- CodexAstraLocal: Separate measured creation acceptance from gameplay qualification. -->
On the Thor's existing Qualcomm driver, a bounded pipeline-creation probe
reproduced the exact captured .46 rejection (`VK_ERROR_UNKNOWN`) and successfully
created both replacement .47 stages. No draw was dispatched by this probe, so
this establishes compatibility for that captured program, not successful game
startup or complete Calculated rendering.

<!-- CodexAstraLocal: Local checks cover changed contracts; publication still requires every existing gate. -->
The native test target builds. Seven Software cases pass 1,188 assertions.
Calculated host comparisons preserve complete color/depth/output/state for the
tested groups, packed targets, failure contracts and uniform addressing. The new
Vulkan image-descriptor gate passes 41 draws and 562 checks, including executed
defect controls; it is part of the required shader workflow. The existing
shader/Android/signing/publication gates remain required for this release.

Calculated's retained midpoint-color discrepancy remains open. CPU Software was
still near 2% speed during the .46 Dark Moon startup probe; these optimizations
do not establish playability. Both experimental modes require actual .47 gameplay
qualification. Native/Combo performance gains also remain unmeasured on .47.
