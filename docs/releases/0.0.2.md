# Uberhar 0.0.2

Second alpha for Android ARM64, based on Azahar 2126.1.2. The initial APK failed
normal installation because it accidentally carried Android's `testOnly` flag.
This release fixes packaging; the experimental renderer is unchanged.

Download **uberhar-0.0.2-arm64.apk** from the release assets and tap it to install.
It uses the separate **Uberhar Alpha** app identity. Choose an empty Uberhar
data folder; keep your Azahar installation and its data folder separate.

- Removed IDE ABI injection and explicitly disabled test-only packaging.
- Added final-manifest checks for install flags, package/version, SDK requirements,
  launcher entry point, provider-authority conflicts, permissions and required Java libraries.
- Check ZIP integrity, AArch64 ELF headers, native dependencies, APK alignment,
  signature validity and the existing development signing certificate before publishing.
- Version numbers follow **release.beta.alpha**: this build is **0.0.2**.
- Code changes retain **AstraEH** attribution comments.

For the first shader test, select Vulkan, turn off **Enable SPIR-V shader generation**,
and compare the same scene with **Uberhar hybrid TEV** off and on. Leave
**Force TEV fallback** off initially. Restart the game after changing these options.
The full [testing guide](https://github.com/RegiRex/uberhar/blob/uberhar/hybrid-shaders/UBERHAR.md#first-device-test)
explains cold/warm caches and useful logs.

This is a limited texture-combiner fallback experiment. New shader families and
vertex shaders can still stall. No Thor performance improvement or compatibility
with every game, driver or third-party launcher has been established. Screen
synchronization and model-clarity work are later phases.
