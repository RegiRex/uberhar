select ready full/static specializations before creating or waiting for a generic

work is distinct from resident ready pipelines, so generic fallback can remain
necessary. This does not establish a steady-state speedup or fix Luigi's Mansion:
Dark Moon's earlier rendering/crash reports. See the [architecture and limits](../UBERHAR_PRECOMPILATION.md).
