# Uberhar 0.1.36 — broader useful ARM64 vertex parallelism

<!-- CodexAstraLocal: Describe the candidate's exact output contract without

Native and Combo can distribute more CPU vertex work across available processors.
A new dependency proof admits programs whose carried temporary values cannot
affect selected output or control flow. The same shader arithmetic executes in
bounded worker batches; FIFO discovery and primitive submission retain their
original order. This removes unnecessary serialization without recording and
replaying unused carried state. No saved application shader cache is required,
and no guest draw is skipped by this change.

The wider contract is limited to the explicitly audited ARM64 shader JIT and
ARM64 guest CPU backend. Geometry shaders, diagnostics, enabled FP traps,
concurrent guest-memory writers and unsupported input/control-flow cases retain
their existing safeguards. The original arithmetic-read certificate remains the
default for other callers. Cache identity includes the chosen contract, so an
unchanged source revision cannot reuse a proof from a different domain.

Unused temporary state and incidental host FP flags may differ under this scoped
renderer contract. Selected vertex bytes, guest CPU floating status and FP controls
must remain correct. The [contract document](../UBERHAR_OBSERVABLE_VERTEX_CONTRACT.md)
records the consumer boundary and the conditions future changes must revalidate.

ARM64 shader writeback also uses exact narrow stores for single components and
aligned component pairs, avoiding redundant destination reads and blending.
Arithmetic, live output-bank selection and all disabled components are preserved.
The ordinary parallel report now identifies work admitted by the selected-output
contract and weights completed serial refusals by actual shader invocations.
Counts describe work populations; they do not measure CPU time.

Local tests execute the actual ARM64 emitters and CPU backend under NDK/QEMU.
They check raw writeback state, guest-status isolation, selected output, FIFO/chunk
boundaries and persistent primitive order. Deliberately broken implementations must
fail their output/status assertions. The existing ARM64 return, full-arithmetic,
cache, ownership, shader and Android/signing gates remain required; three new ARM64
gates run before packaging. Independent architecture and cleanliness review and
current merged-source validation precede publication.

Local merged compilation and CTest pass with five existing firmware-dependent
skips. Current-emitter validation covers 2,785,280 A64 calls, 168 composed draws
and ten output-sensitive defects; the original certificate suite still passes.
Guest status isolation covers 29,952 executions and three backend defects. Exact
writeback covers 29,568 raw-state/status pairs and four machine defects. These are
finite correctness checks, not complete-title performance measurements.

This is an experimental alpha. Thor Native/Combo speed, sustained CPU use and
consecutive-frame graphics results are pending for this build. Sustained 99%
normal speed, 4x resolution and broader gameplay remain unqualified. Independent
Calculated rendering continues as a separate prototype and is not added here.
